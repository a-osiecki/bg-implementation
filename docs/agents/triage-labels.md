# Triage labels

Los skills hablan en términos de cinco roles canónicos. Este archivo mapea cada rol al label que usa este repo.

| Label en el stack | Label en este repo | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | El mantenedor tiene que evaluarlo |
| `needs-info` | `needs-info` | Esperando información de quien reportó |
| `ready-for-agent` | `ready-for-agent` | Especificado del todo, listo para un agente AFK |
| `ready-for-human` | `ready-for-human` | Necesita implementación humana |
| `wontfix` | `wontfix` | No se va a hacer |

Cuando un skill mencione un rol, usar el label de la columna del medio.
